02 — Featured Project

VEX V5 Medbot

My completed robotics project and what I learned while working through the challenge.

What is Medbot?

Medbot is a VEX V5 STEM Lab focused on robot behaviors and programming. The lab has students build the V5 Speedbot and then use programming concepts to control the robot. It has a wattage of 11, 200 rpm, A 4m wheel diameter, and an inertial sensor that tells the robot how much it has turned

The skills learned throughout the lab prepare you for the final Automed Challenge.

What I Had to Do

  • Build the V5 Speedbot.
  • Learn forward and reverse movement.
  • Learn left and right turns.
  • Plan a robot route.
  • Program the robot.
  • Test and improve the program.
  • Complete the Automed Challenge.
The Build

Building the Speedbot

Starting With the Build

Before programming the challenge, I built the VEX V5 Speedbot by following the build instructions.

The Speedbot provided the physical structure for the programming activities. Building it also helped me understand how the motors, drivetrain, brain, and other components work together.

Programming

The Coding Challenge

I programmed the Speedbot to navigate a hospital layout and deliver medication.

🤖 How the challenge works

The robot begins in the Start Zone and must navigate through the hospital. It travels to the Pharmacy, waits to pick up medication, then travels to the patient rooms.


At each patient room, the robot needs to stop for the required amount of time to simulate delivering medication. The robot also uses the Elevator area when moving between floors. After visiting the patient rooms, it returns to the Start Zone.


The challenge required me to think about the robot's movements before writing the program, test the route, find mistakes, and make changes until the robot could complete the task.
