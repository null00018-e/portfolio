Robotics Project • Speedy Delivery

Speedbot
Package Delivery

For this project, we worked with a robot that had to pick up three packages and deliver them to their drop-off locations. The challenge involved more than just driving: the robot needed to move carefully, control its attachment, and follow a sequence of actions so each package could be collected and dropped off.

Building and testing Speedbot
The Challenge

Three packages, one route

The goal was to collect all three packages and drop them off. To do that, we had to think about the order of the movements, where the robot needed to stop, and how to operate the mechanism without losing a package.

01 — PICK UP

Collect a package

Move into position and use the robot's attachment to pick up the package.

02 — NAVIGATE

Drive to the drop-off

Control the robot's movement so it reaches the delivery location without knocking the package loose.

03 — DELIVER

Release and repeat

Drop off the package, then repeat the process until all three packages have been delivered.

What I Practiced

Planning, coding, and testing

This project gave us practice breaking a larger task into smaller steps. We had to coordinate driving with the package mechanism, make the robot stop in the right places, and test the sequence to see whether all three deliveries worked.

If a pickup or drop-off did not work correctly, we could adjust the movement or timing and test again. It showed how small changes in a robot's code or mechanical setup can affect the whole task.
