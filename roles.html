Medbot Team

My Role

My main role on the Medbot project was programming. I was absent during the first few days, so I was not able to help build the robot at the beginning. Cooper and Hunt built and coded the robot during those first few days. When I was able to join the project, I mainly focused on the programming and making sure the robot could complete its challenge.

Medbot Programmer

I worked mainly on the code that controlled the Speedbot through the hospital challenge. The program had to make the robot start in the Start Zone, navigate through the hospital, travel to the Pharmacy, wait to pick up the medication, and then travel to the patient rooms.

  • Planned the robot's route through the hospital layout.
  • Programmed the robot's movements and sequence of actions.
  • Used timing to simulate medication delivery at patient rooms.
  • Included the Elevator area as part of the route.
  • Tested the program to find mistakes in the route or movements.
  • Changed and retested the code until the robot could complete the challenge.
  • Worked with the team to make the programming fit the robot that had been built.

What I Contributed

Even though I missed the initial building phase, programming became my main contribution to Medbot. I had to think through the robot's movements before writing the program, test the route, find problems, and make changes when something did not work correctly. This gave me experience with planning, C++ programming, testing, and debugging as part of a robotics team.
