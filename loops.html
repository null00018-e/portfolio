Loops &
Functions

For the “Loop There It Is” challenge, we took a slightly different approach instead of following the activity exactly. We made three separate loops—a for loop, a repeat-style loop, and a while loop—and then used functions to organize them so the different loop routines could be run together. This let us practice more than one way to repeat instructions in our robot program.

Three kinds of loops

How each loop works

01 — FOR LOOP

Repeats a set number of times

A for loop is useful when you know how many times you want the code to run. It has a starting value, a condition that determines when to stop, and an update that changes the counter each time.

In my code, lincicome starts at 0, runs while it is less than or equal to 10, and increases by 1 each pass. That means the loop goes through the values 0 through 10.

02 — REPEAT LOOP

Repeats a chosen number of times

A repeat loop runs the instructions inside it a specified number of times. It is useful when you want the robot to perform the same action sequence a fixed number of times without writing that sequence over and over.

For example, a repeat loop can repeat a movement or action sequence for however many repetitions the program specifies.

03 — WHILE LOOP

Repeats while a condition is true

A while loop checks a condition before each pass. If the condition is true, the code inside runs; then the condition is checked again. It stops when the condition becomes false.

This is useful when the robot should keep doing something until a condition changes, rather than stopping after a preset number of repetitions.

My code

Looking inside the for loop

Screenshot from my VEXcode C++ program. The visible section shows the for loop and the arm motor commands inside it.

START & COUNT

int lincicome = 0;

This creates the counter and sets its starting value to 0. The for statement then checks lincicome <= 10 and adds 1 with lincicome++ after each pass.

CHECK THE VALUE

if (lincicome == 0)

When the counter is 0, the program prints 0. For the other values, the else section prints pow(lincicome, lincicome)—the current number raised to itself.

MOVE THE ARM

Forward, wait, reverse

For values other than 0, the arm motor spins forward by lincicome squared degrees, waits 5 seconds, and then spins backward by the same number of degrees. This makes the arm move out and return during each pass.

What I learned: Loops make it possible to repeat instructions without copying the same code many times. Functions help keep the program organized by putting each set of instructions into its own named section. In our challenge, we used that organization to bring the three loop routines together.
