Clawbot Controller

For this project, I programmed a Clawbot to be controlled with a VEX controller. I used functions to separate the driving styles from the arm and claw controls. This made the code easier to organize because each controller button could call the function for the action I wanted.

01

Using functions for driving

I made three driving functions: tank(), arcade(), and Left(). Each function contains its own while (true) loop, so it keeps checking the controller and updating the motors while that driving mode is active.

In tank(), Axis 3 controls the left motor and Axis 2 controls the right motor separately. In arcade(), Axis 3 controls forward and reverse, while Axis 1 adds turning. In Left(), Axis 3 is combined with Axis 4 to control forward movement and turning.

Each loop checks whether certain buttons are being pressed. If one of those buttons is pressed, break exits that loop, allowing the driving function to finish.

02

Connecting buttons to functions

In main(), I used the controller's pressed() event to connect each button to a function. For example, pressing X calls tank, pressing A calls arcade, and pressing B calls Left.

This means I did not have to put all of the driving code directly inside main(). Instead, the button tells the program which function to run.

The screenshot shows the button-to-function connections in main().

03

Controlling the arm and claw

I also made four functions for the two extra motors. controller_L1_Pressed() spins the arm forward while L1 is held, and controller_L2_Pressed() spins it in reverse while L2 is held.

For the claw, controller_R1_Pressed() spins the claw motor in reverse while R1 is held, and controller_R2_Pressed() spins it forward while R2 is held.

Inside each function, a while loop keeps checking whether the button is still being pressed. Once the button is released, the loop ends and stop() stops that motor. This makes the arm and claw respond for only as long as I hold their buttons.

04

Reading the driving code

This screenshot shows part of the arcade() function. The controller axis positions are used as motor velocities, measured in percent. The left motor uses Axis 3 plus Axis 1, while the right motor uses Axis 3 minus Axis 1. Combining the axes lets one stick control forward movement and turning together.

The motors are then told to spin forward. The if statement checks for the exit buttons, and break ends the loop when one is pressed. wait(5, msec) briefly pauses the loop before it checks the controller again.

The visible code is the end of the arcade() function.

05

What I learned

Using functions helped me split the program into smaller parts that each had a specific job. The driving functions handled different ways to steer, while the four button functions controlled the arm and claw. I also used while loops to keep the motors responding while a button was held, and button events in main() to choose which function should run.
